# Namal-MedCare

**Project Summary**

The Namal-MedCare (NMC) system provides a centralized digital web application for managing medical records and medicine inventory at the Namal University dispensary. The system replaces the current manual record-keeping process and allows authorized medical personnel to efficiently record, update, search, and retrieve student and staff medical histories, allergies, and emergency blood data. Additionally, it tracks medicine inventory records, monitoring batch numbers, stock levels, and expiration dates to automatically trigger low-stock and expiry notifications.

### Tech Stack
*   **Figma:** Interface design and wireframing
*   **MySQL:** Relational database management and schema implementation
*   **Python with Django:** Backend application logic, security authentication, and alert generation
*   **HTML5, CSS3, and JavaScript:** Frontend layout structure and user interface behaviors
*   **Bootstrap:** Frontend UI component responsiveness
*   **Git and GitHub:** Code version control and team project monitoring boards
*   **draw.io:** System architecture and UML diagram models
*   **MySQL Workbench:** Database E-R diagram modeling and SQL testing
*   **Visual Studio Code:** Primary development code editor
